# MacPlus Software Homebrew tap

Homebrew casks for Mac apps made by MacPlus Software.

## Get started

```sh
brew tap macplus-software/tap
brew install --cask macplus-software/tap/<app>
```

Each app below lists its own install command. Apps that update themselves keep doing so after a Homebrew install.

## Apps

### ActiveDock 2

A dock replacement you can shape around the way you work. It previews and manages windows, groups apps and documents into folders, adds a start menu style launcher, and supports themes and custom icons.

```sh
brew install --cask macplus-software/tap/activedock
```

More: https://noteifyapp.com/activedock/

### ClipboardGrid

Press a shortcut and your recent copies appear as large cards across the screen: text, links, images and files. Paste one with a number key, pin the items you reuse, and search everything you copied. History stays on your Mac.

```sh
brew install --cask macplus-software/tap/clipboardgrid
```

More: https://noteifyapp.com/clipboardgrid/

### Command-Tab Plus 2

A faster, more capable stand-in for the built-in app switcher. Jump to an app with a number key, switch between windows of the selected app, and limit the list to the current display or Space. Hotkeys, filters and skins are configurable.

```sh
brew install --cask macplus-software/tap/command-tab-plus
```

More: https://noteifyapp.com/command-tab-plus/

### DockView 2

Hover over an app in the Dock to see live previews of all its windows, then click the one you want. It works with Stage Manager, multiple displays and full-screen Spaces, and it previews windows minimized to the Dock as well.

```sh
brew install --cask macplus-software/tap/dockview
```

More: https://noteifyapp.com/dockview/

### FlexiNet

A small menu bar app that shows the current macOS network location and lets you switch to another one in a click. Handy when you move between home, office and test setups that need different network settings.

```sh
brew install --cask macplus-software/tap/flexinet
```

More: https://noteifyapp.com/flexinet/

### MaxSnap

A window manager for moving and resizing windows without careful mouse work. Use preset layouts from the keyboard or the menu bar, drag a window from anywhere while holding a modifier key, or arrange windows with trackpad swipes across Spaces and displays.

```sh
brew install --cask macplus-software/tap/maxsnap
```

More: https://noteifyapp.com/maxsnap-mac-window-manager/

### SuperTab 7

One panel on Option-Tab that brings together running apps, every window of every app, clipboard history, recent documents and your favorite files. Arrange the rows you need and keep separate sets for different kinds of work.

```sh
brew install --cask macplus-software/tap/supertab
```

More: https://noteifyapp.com/supertab/

### Tab Finder 2

Collects the open tabs from your browser windows into one searchable list, so you can find a tab and jump to it from the keyboard. Works with Safari and Chromium-based browsers, with light and dark themes.

```sh
brew install --cask macplus-software/tap/tab-finder
```

More: https://noteifyapp.com/tab-finder/
